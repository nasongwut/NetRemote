# NetRemote — Remote Desktop สำหรับวง LAN

ดูหน้าจอ + ควบคุมเมาส์/คีย์บอร์ดของอีกเครื่องผ่านเครือข่าย เข้ารหัส TLS และยืนยันตัวตนด้วยรหัสผ่าน

## ดาวน์โหลดโปรแกรม (.exe / .dmg)
แท็บ **Actions** → เลือกรายการ Build ล่าสุดที่มี ✓ → หัวข้อ **Artifacts**
- `NetRemote-Windows` → `NetRemote.exe`
- `NetRemote-macOS` → `NetRemote-macOS-arm64.dmg` (Mac ชิป Apple Silicon)

## รันจากโค้ด
- macOS: ดับเบิลคลิก `Remote Desktop.command`
- Windows: ดับเบิลคลิก `Remote Desktop (Windows).bat`

รายละเอียดการใช้งานดูที่ `วิธีใช้ Remote Desktop.txt`
