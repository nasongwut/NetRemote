NetRemote — คู่มือการใช้งาน
===========================
ดูหน้าจอ + ควบคุมเมาส์/คีย์บอร์ด + รับ-ส่งไฟล์ ของอีกเครื่อง
ค้นหาเครื่องด้วย ID 9 หลักผ่าน Relay Server — ถ้าสองเครื่องต่อหากันได้ จะเชื่อมต่อตรง (เร็วกว่า ไม่ผ่าน Server)
ต้องติดตั้งโปรแกรมนี้ทั้ง 2 เครื่อง และต้องมี Relay Server 1 ตัว (ดู relay/README.md)

เปิดโปรแกรม
  macOS   : ดับเบิลคลิก "Run on Mac.command"  (หรือ NetRemote.app ที่ Build แล้ว)
  Windows : ดับเบิลคลิก "Run on Windows.bat"  (หรือ NetRemote.exe ที่ Build แล้ว)

-----------------------------------------------
0) ตั้งค่า Server (ทำครั้งเดียว)
-----------------------------------------------
  วิธีที่ 1 — ผู้ดูแลระบบใส่ค่าในไฟล์ .env ก่อน Build (แนะนำ)
        RELAY_ADDR=ที่อยู่ Server เช่น relay.cityart.co.th:5910
        RELAY_KEY=ต้องตรงกับ RELAY_KEY ในไฟล์ relay/.env
    ค่าจะถูกฝังใน .app / .exe ผู้ใช้ไม่ต้องตั้งค่าอะไร (ช่องในโปรแกรมถูกล็อก 🔒)
  วิธีที่ 2 — ในโปรแกรม
    แท็บ "ตั้งค่า Server" → ใส่ "ที่อยู่ Server" + "Server Key" → บันทึก

  ป้ายสถานะมุมขวาบนของโปรแกรม (อัปเดตอัตโนมัติ):
    🟢 Server ออนไลน์ · 18 ms        เชื่อมต่อได้ (แสดง Ping)
    🟢 … · พร้อมรับการเชื่อมต่อ      เครื่องนี้ออนไลน์รอให้คนอื่นเชื่อมต่อ
    🟠 กำลังเชื่อมต่อ…
    🔴 Server: เชื่อมต่อไม่ได้        กดที่ป้ายเพื่อดูสาเหตุในแท็บ ตั้งค่า Server
    ⚪ ยังไม่ได้ตั้งค่า Server

  ⚡ เชื่อมต่อตรงเมื่อทำได้ (เปิดไว้เป็นค่าเริ่มต้น — แท็บ "ตั้งค่า Server")
    ทุกครั้งที่เชื่อมต่อ โปรแกรมหาเครื่องด้วย ID และยืนยันผ่าน Server ก่อน แล้ว:
      1. ลองต่อตรงระหว่างสองเครื่อง (ใช้เวลาไม่เกิน 3 วินาที)
      2. ต่อตรงได้   → ภาพ/เมาส์/ไฟล์ วิ่งตรงระหว่างเครื่อง ไม่ใช้ Bandwidth ของ Server
         ต่อตรงไม่ได้ → ใช้ Server ส่งต่อให้อัตโนมัติ (เหมือนเดิม)
    หน้าต่างรีโมทจะแสดง  "⚡ ต่อตรง"  หรือ  "☁ ผ่าน Server"
    ต่อตรงได้เมื่อ: อยู่วง LAN / VPN เดียวกัน (หรือตั้ง DIRECT_PORT + Port Forward ที่ Router)
    ข้ามอินเทอร์เน็ตต่างที่กัน ส่วนใหญ่จะใช้ Server
    ความปลอดภัย: เครื่องปลายทางเปิดพอร์ตชั่วคราวไม่เกิน 20 วินาที และรับเฉพาะผู้ที่ได้รหัสครั้งเดียวจาก Server
                 จากนั้นยังต้องผ่าน TLS + รหัสผ่านเหมือนเดิม
    ครั้งแรกที่ต่อตรง Mac/Windows อาจถามให้ "อนุญาตการเชื่อมต่อขาเข้า" → กดอนุญาต
      (ถ้ากดไม่อนุญาต ก็ยังใช้ได้ แต่จะวิ่งผ่าน Server)

  อัปเดตโปรแกรม
    โปรแกรมตรวจหาเวอร์ชันใหม่จาก Server ตอนเปิด และทุก 6 ชั่วโมง
    ถ้ามี จะขึ้นป้าย "⬆ มีอัปเดต x.y" สีส้มมุมบน → กดป้าย → "ดาวน์โหลด"
    ไฟล์ลงโฟลเดอร์ Downloads (ตรวจ SHA-256 ให้แล้ว)
      Mac     : เปิด .dmg ให้อัตโนมัติ → ลาก NetRemote ไปทับใน Applications
      Windows : เปิดโฟลเดอร์ที่มี NetRemote.exe → ปิดโปรแกรมเก่าแล้วใช้ไฟล์ใหม่แทน
    ตรวจเองได้: แท็บ "ตั้งค่า Server" → "ตรวจสอบอัปเดต"
    (ผู้ดูแล: วิธีปล่อยเวอร์ชันใหม่ ดู relay/README.md หัวข้อ 8)

-----------------------------------------------
1) เครื่องที่จะถูกควบคุม
-----------------------------------------------
  - เปิดโปรแกรมไว้ก็พร้อมรับการเชื่อมต่ออัตโนมัติ (แท็บ "ให้เครื่องอื่นควบคุมเครื่องนี้")
  - แจ้ง ID 9 หลัก + รหัสผ่าน ให้อีกฝั่ง (ปุ่ม "คัดลอก")
  - การ์ดสถานะ: เทา = ปิดอยู่, เขียว = พร้อมรับ, แดง = กำลังถูกควบคุม (แสดงผู้ควบคุม + Latency)
  - "ถามก่อนรับการเชื่อมต่อ" / "อนุญาตให้ควบคุม" / "อนุญาตให้รับ-ส่งไฟล์" เปิด-ปิดได้
  - เครื่องนี้ไม่เปิดพอร์ตถาวร — เปิดชั่วคราวเฉพาะตอนมีคนขอเชื่อมต่อตรงผ่าน Server

  ★ macOS ต้องให้สิทธิ์ (System Settings > Privacy & Security) กับ NetRemote (หรือ Terminal):
       • Screen Recording   (ถ้าไม่ให้ อีกฝั่งเห็นแค่ภาพพื้นหลัง)
       • Accessibility      (ถ้าไม่ให้ อีกฝั่งควบคุมไม่ได้)

-----------------------------------------------
2) เครื่องที่จะควบคุม
-----------------------------------------------
  - แท็บ "ควบคุมเครื่องอื่น" → ใส่ ID 9 หลัก + รหัสผ่าน → "เชื่อมต่อ"
  - "เครื่องที่เคยเชื่อมต่อ" ด้านขวา — ดับเบิลคลิกเพื่อเลือก
  - หน้าต่างรีโมท:
      คุณภาพ · ควบคุม (เอาติ๊กออก = ดูอย่างเดียว) · สลับ ⌘↔Ctrl
      ● xx ms   Latency (เขียว ดี / ส้ม พอใช้ / แดง ช้า)
      📁 ไฟล์ · ✎ ข้อความ (พิมพ์ภาษาไทยได้) · ⟲ ปล่อยปุ่ม · ⛶ เต็มจอ · ตัดการเชื่อมต่อ

-----------------------------------------------
3) รับ-ส่งไฟล์ (ปุ่ม 📁 ไฟล์)
-----------------------------------------------
  หน้าต่าง 2 ฝั่ง:   ซ้าย = เครื่องนี้ (This device)   ขวา = เครื่องปลายทาง (Remote device)
  - แต่ละฝั่ง: ← ย้อนกลับ · ↑ ขึ้น · ⌂ Home · ⟳ รีเฟรช · ช่อง path (พิมพ์หรือเลือก)
  - ⬆ Upload   ส่งไฟล์/โฟลเดอร์ที่เลือกฝั่งซ้าย → โฟลเดอร์ที่เปิดอยู่ฝั่งขวา
  - ⬇ Download รับไฟล์/โฟลเดอร์ที่เลือกฝั่งขวา → โฟลเดอร์ที่เปิดอยู่ฝั่งซ้าย
  - ลากไฟล์ข้ามฝั่ง = ส่ง/รับ · ดับเบิลคลิกโฟลเดอร์ = เปิด · ดับเบิลคลิกไฟล์ = ส่ง/รับ
  - ✕ ลบ · + โฟลเดอร์ใหม่ (ทำได้ทั้งสองฝั่ง — บน Mac ไฟล์ที่ลบจะไปอยู่ถังขยะ)
  - คลิกหัวคอลัมน์ Name / Modified / Size เพื่อเรียง
  - ด้านล่างแสดงความคืบหน้า ความเร็ว ยกเลิกได้ — ไฟล์ที่ส่งไม่ครบถูกลบอัตโนมัติ
  - ชื่อไฟล์ซ้ำจะตั้งชื่อใหม่เป็น "ชื่อ (1)" ไม่เขียนทับของเดิม

-----------------------------------------------
ไฟล์ .env (สำหรับผู้ดูแลระบบ — ดูตัวอย่างใน .env.example)
-----------------------------------------------
  RELAY_ADDR, RELAY_KEY, HOST_PASSWORD, ASK_BEFORE_ACCEPT, ALLOW_CONTROL,
  ALLOW_FILES, THEME (auto/light/dark), DOWNLOAD_DIR, DIRECT_CONNECT, DIRECT_PORT
  ลำดับการค้นหา: $NETREMOTE_ENV → ~/.netremote/.env → โฟลเดอร์โปรแกรม → ฝังในโปรแกรม

ความปลอดภัย
  - เข้ารหัส TLS ต้นทางถึงปลายทาง ทั้งแบบต่อตรงและผ่าน Server — Server อ่านหน้าจอ/ไฟล์ไม่ได้
  - รหัสผ่านไม่ถูกส่งผ่านเครือข่าย (HMAC) · ผิด 3 ครั้งบล็อก 60 วินาที
  - ถ้า Certificate ของปลายทางเปลี่ยน โปรแกรมจะเตือนก่อนเชื่อมต่อ
  - ไฟล์ตั้งค่า/Certificate เก็บที่ ~/.netremote/
