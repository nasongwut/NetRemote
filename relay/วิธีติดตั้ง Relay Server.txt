NetRemote Relay Server — สำหรับรีโมทผ่านอินเทอร์เน็ต
=====================================================
Relay คือ "ตัวกลาง" ที่ทั้งเครื่องควบคุมและเครื่องถูกควบคุมเชื่อมต่อออกไปหา
→ ไม่ต้องตั้ง Port Forward ที่ Router บ้าน/ออฟฟิศ
→ ข้อมูลเข้ารหัส TLS จากต้นทางถึงปลายทาง Relay อ่านหน้าจอ/ไฟล์/รหัสผ่านไม่ได้
→ เชื่อมต่อด้วย ID 9 หลัก (เหมือน AnyDesk / TeamViewer)

ต้องมีเครื่องที่มี IP สาธารณะ 1 เครื่อง เช่น VPS (DigitalOcean, Vultr, Linode, AWS Lightsail,
Google Cloud, Azure, หรือ VPS ไทย) — สเปกต่ำสุดก็พอ (1 CPU / 512MB RAM) ใช้ Linux (Ubuntu แนะนำ)

-----------------------------------------------------
ขั้นตอนติดตั้งบน VPS (Ubuntu / Debian)
-----------------------------------------------------
1) เปิดพอร์ต TCP 5910 ที่ Firewall ของผู้ให้บริการ (Security Group / Cloud Firewall)
   และในเครื่อง:   sudo ufw allow 5910/tcp

2) คัดลอกไฟล์ขึ้น VPS (รันบน Mac ในโฟลเดอร์ Remote Desktop/relay):
     scp relay_server.py netremote-relay.service root@IP_ของ_VPS:/tmp/

3) SSH เข้า VPS แล้วรัน:
     sudo mkdir -p /opt/netremote-relay
     sudo cp /tmp/relay_server.py /opt/netremote-relay/
     sudo cp /tmp/netremote-relay.service /etc/systemd/system/
     sudo nano /etc/systemd/system/netremote-relay.service
        → แก้ YOUR-RELAY-KEY เป็นรหัสของคุณ (ยาว ๆ เดายาก) แล้วบันทึก
     sudo systemctl daemon-reload
     sudo systemctl enable --now netremote-relay

4) ตรวจสอบว่าทำงาน:
     sudo systemctl status netremote-relay
     sudo journalctl -u netremote-relay -f      (ดู log แบบสด กด Ctrl+C เพื่อออก)

   ทดลองรันแบบชั่วคราว (ไม่ติดตั้งเป็น service):
     python3 relay_server.py --port 5910 --key รหัสของคุณ

-----------------------------------------------------
ตั้งค่าในโปรแกรม NetRemote (ทั้ง 2 เครื่อง)
-----------------------------------------------------
แท็บ "อินเทอร์เน็ต (Relay)":
   Relay Server : IP_ของ_VPS:5910   (หรือโดเมน เช่น relay.cityart.co.th:5910)
   Relay Key    : รหัสเดียวกับที่ตั้งใน service
   กด "ทดสอบการเชื่อมต่อ Relay" → ต้องขึ้น ✓

เครื่องที่จะถูกควบคุม:
   ติ๊ก "ให้เครื่องนี้รับการเชื่อมต่อผ่านอินเทอร์เน็ต" → บันทึก
   ไปแท็บ "ให้เครื่องอื่นควบคุมเครื่องนี้" → กด เริ่มเปิดรับ
   จะเห็น ID 9 หลัก และ "ออนไลน์ผ่าน Relay" สีเขียว → แจ้ง ID + รหัสผ่านให้อีกฝั่ง

เครื่องที่ควบคุม:
   แท็บ "ควบคุมเครื่องอื่น" → ช่อง IP / ID ใส่ ID 9 หลัก (เช่น 601 272 688) + รหัสผ่าน → เชื่อมต่อ

-----------------------------------------------------
ความปลอดภัย / ข้อควรรู้
-----------------------------------------------------
- Relay Key กันไม่ให้คนอื่นใช้ Relay ของคุณ (ควรตั้งเสมอ)
- แต่ละ ID ผูกกับเครื่องที่ลงทะเบียนครั้งแรก เครื่องอื่นจะแอบใช้ ID เดียวกันไม่ได้
  (ข้อมูลเก็บที่ /var/lib/netremote-relay/relay_ids.json)
- จำกัดการเชื่อมต่อ 60 ครั้ง/นาที ต่อ IP และสูงสุด 50 เซสชันพร้อมกัน (--max-sessions)
- ข้อมูลทุกอย่างผ่าน Relay จึงใช้ Bandwidth ของ VPS:
    รีโมทปกติ ~0.2–3 Mbps ต่อเซสชัน, รับ-ส่งไฟล์ใช้ตามขนาดไฟล์
- ใช้ Relay ที่อยู่ใกล้ (เช่น VPS ในไทย/สิงคโปร์) Latency จะต่ำกว่า
- Relay ใช้แค่ Python 3 ไม่ต้องติดตั้งอะไรเพิ่ม

-----------------------------------------------------
หน้ามอนิเตอร์ (ดูว่ามีใครเชื่อมต่ออยู่บ้าง)
-----------------------------------------------------
Relay มีหน้าเว็บมอนิเตอร์ในตัว (พอร์ต 5911) แสดง:
  - เครื่องที่ออนไลน์ (ID, ชื่อเครื่อง, IP, ออนไลน์มานานเท่าไร, ว่าง/กำลังถูกควบคุม)
  - ใครกำลังรีโมทเข้าเครื่องไหน (IP ผู้ควบคุม → เครื่องปลายทาง, เวลา, ปริมาณข้อมูล, ความเร็ว)
  - ปุ่ม "ตัดการเชื่อมต่อ" / "ตัดออก"
  - เหตุการณ์ล่าสุด (ออนไลน์/ออฟไลน์, เริ่ม/เลิกเชื่อมต่อ, ใส่ Relay Key ผิด)
  - อัปเดตอัตโนมัติทุก 2 วินาที รองรับโหมดมืด

เปิดดู:
  • รัน Relay บน Mac เครื่องนี้ → เปิดเบราว์เซอร์ไปที่  http://localhost:5911
  • รัน Relay บน VPS (ค่าเริ่มต้นเปิดให้ดูจากตัว VPS เท่านั้น เพื่อความปลอดภัย) เลือกวิธีใดวิธีหนึ่ง:
      ก) ใช้ SSH Tunnel (แนะนำ ปลอดภัยที่สุด) — รันบน Mac:
           ssh -L 5911:localhost:5911 root@IP_ของ_VPS
         แล้วเปิด http://localhost:5911 บน Mac
      ข) เปิดให้ดูจากที่อื่นได้: เพิ่ม  --web-bind 0.0.0.0  (และเปิดพอร์ต 5911 ใน Firewall)
         จะต้องใส่รหัส Admin (ชื่อผู้ใช้อะไรก็ได้ / รหัส = Relay Key หรือ --admin-key)
         ใน service ให้เพิ่มบรรทัด  Environment=RELAY_WEB_BIND=0.0.0.0
  • ปิดหน้ามอนิเตอร์: --web-port 0
