NetRemote — โปรแกรม Remote Desktop สำหรับวง LAN
================================================
ดูหน้าจอและควบคุมเมาส์/คีย์บอร์ดของอีกเครื่องผ่านเครือข่าย
ต้องติดตั้งโปรแกรมนี้ทั้ง 2 เครื่อง (เครื่องที่ควบคุม และเครื่องที่ถูกควบคุม)

เปิดโปรแกรม
  macOS   : ดับเบิลคลิก "Remote Desktop.command"
            (ครั้งแรกถ้าเปิดไม่ได้ ให้คลิกขวา > Open และรอติดตั้งประมาณ 1-2 นาที)
  Windows : ดับเบิลคลิก "Remote Desktop (Windows).bat"
            (ต้องมี Python 3 จาก python.org และติ๊ก "Add python.exe to PATH" ตอนติดตั้ง)

-----------------------------------------------
1) เครื่องที่จะถูกควบคุม
-----------------------------------------------
  - ไปแท็บ "ให้เครื่องอื่นควบคุมเครื่องนี้" แล้วกด "เริ่มเปิดรับการเชื่อมต่อ"
  - แจ้ง IP และรหัสผ่านที่แสดงให้อีกฝั่ง (ปุ่ม "คัดลอก" ช่วยได้)
  - ถ้าติ๊ก "ถามก่อนรับการเชื่อมต่อ" จะมีหน้าต่างให้กดอนุญาตทุกครั้ง
  - แถบสีแดงหมายถึงกำลังถูกควบคุม กด "ตัดการเชื่อมต่อ" ได้ทุกเมื่อ

  ★ macOS ต้องให้สิทธิ์ 2 อย่างกับแอป "Terminal" (ทำครั้งเดียว)
     System Settings > Privacy & Security >
       • Screen Recording        → เปิด Terminal   (ถ้าไม่เปิด อีกฝั่งจะเห็นแค่ภาพพื้นหลัง)
       • Accessibility           → เปิด Terminal   (ถ้าไม่เปิด อีกฝั่งจะควบคุมไม่ได้)
     จากนั้นปิดโปรแกรมแล้วเปิดใหม่ — ในแท็บจะแสดง ✓ เมื่อได้รับสิทธิ์แล้ว
  ★ ถ้า Firewall ถามว่าอนุญาตให้รับการเชื่อมต่อหรือไม่ → กด Allow

-----------------------------------------------
2) เครื่องที่จะควบคุม
-----------------------------------------------
  - ไปแท็บ "ควบคุมเครื่องอื่น"
  - ใส่ IP และรหัสผ่าน แล้วกด "เชื่อมต่อ"
    (หรือกด "ค้นหา" เพื่อหาเครื่องในวง LAN ที่เปิดรับอยู่ แล้วดับเบิลคลิก)
  - หน้าต่างรีโมท:
      คุณภาพ        ประหยัด / ปกติ / คมชัด / สูงสุด
      ควบคุมเมาส์/คีย์บอร์ด   เอาติ๊กออก = ดูอย่างเดียว
      สลับ ⌘ ↔ Ctrl  เปิดให้อัตโนมัติเมื่อ Mac ควบคุม Windows (กด ⌘C แล้วเป็น Ctrl+C)
      ส่งข้อความ…   พิมพ์ข้อความยาว ๆ / ภาษาไทย ส่งไปพิมพ์ที่เครื่องปลายทาง
      ปล่อยปุ่มค้าง  ใช้เมื่อปุ่ม Shift/Ctrl ค้างอยู่ที่เครื่องปลายทาง
      เต็มจอ / ตัดการเชื่อมต่อ

ความปลอดภัย
  - ข้อมูลทั้งหมดเข้ารหัสด้วย TLS
  - รหัสผ่านไม่ถูกส่งผ่านเครือข่าย (ใช้ HMAC ยืนยันตัวตน)
  - ถ้าใส่รหัสผ่านผิด 3 ครั้ง IP นั้นจะถูกบล็อก 60 วินาที
  - รับการเชื่อมต่อได้ครั้งละ 1 เครื่อง
  - ถ้า Certificate ของปลายทางเปลี่ยน โปรแกรมจะเตือนก่อนเชื่อมต่อ
  - รหัสผ่านไม่แยกตัวพิมพ์เล็ก-ใหญ่ และไม่สนใจขีด (-) หรือช่องว่าง
  - ใช้ภายในวง LAN เท่านั้น ไม่ควรเปิดพอร์ต 5905 ออกอินเทอร์เน็ต

ข้อจำกัด
  - Windows: ควบคุมหน้าต่างที่รันแบบ Administrator หรือหน้าจอ UAC ไม่ได้
    (ถ้าต้องการ ให้เปิดโปรแกรมนี้ด้วย Run as administrator)
  - Linux: รองรับเฉพาะ X11 (ยังไม่รองรับ Wayland)
  - ⌘Q บน Mac จะปิดหน้าต่างโปรแกรมฝั่งที่กด ไม่ได้ส่งไปเครื่องปลายทาง

ไฟล์ตั้งค่า/Certificate เก็บอยู่ที่ ~/.netremote/

===========================================================
ความสามารถเพิ่มเติม (เวอร์ชันล่าสุด)
===========================================================
Latency
  - หน้าต่างรีโมทแสดง "● Latency xx ms" มุมขวาบน พร้อมสีบอกระดับ
      เขียว = ดีมาก/ดี (< 80 ms)   ส้ม = พอใช้ (80-150 ms)   แดง = ช้า (> 150 ms)
  - แถบล่างแสดง Latency ต่ำสุด / สูงสุด ตั้งแต่เริ่มเชื่อมต่อ
  - เครื่องที่ถูกควบคุมก็เห็น Latency ในแถบสีแดง "กำลังถูกควบคุมโดย …"

รับ-ส่งไฟล์ (File Transfer)
  - ในหน้าต่างรีโมท กดปุ่ม "📁 รับ-ส่งไฟล์"
  - เรียกดูไฟล์บนเครื่องปลายทาง (ขึ้น / Home / พิมพ์ path เองได้)
  - ⬆ อัปโหลดไฟล์… / ⬆ อัปโหลดโฟลเดอร์…  → ส่งไปไว้ในโฟลเดอร์ที่เปิดอยู่
  - ⬇ ดาวน์โหลดที่เลือก (เลือกได้หลายรายการ รวมทั้งโฟลเดอร์) หรือดับเบิลคลิกไฟล์
  - ไฟล์ที่ดาวน์โหลดเก็บที่ ~/Downloads (เปลี่ยนได้)
  - แสดงความคืบหน้า ความเร็ว และยกเลิกได้ — ไฟล์ที่ส่งไม่ครบจะถูกลบอัตโนมัติ
  - ถ้าชื่อไฟล์ซ้ำ จะตั้งชื่อใหม่เป็น "ชื่อ (1).นามสกุล" ไม่เขียนทับของเดิม
  - เครื่องที่ถูกควบคุมปิดได้ที่ช่อง "อนุญาตให้รับ-ส่งไฟล์"

รีโมทผ่านอินเทอร์เน็ต (Relay)
  - ต้องมี Relay Server 1 ตัว (ดูวิธีติดตั้งในโฟลเดอร์ relay/)
  - ตั้งค่าที่แท็บ "อินเทอร์เน็ต (Relay)" ทั้ง 2 เครื่อง
  - เครื่องที่ถูกควบคุมจะได้ ID 9 หลัก → อีกฝั่งใส่ ID แทน IP แล้วกดเชื่อมต่อ
  - ข้อมูลยังเข้ารหัสจากต้นทางถึงปลายทาง Relay อ่านไม่ได้
